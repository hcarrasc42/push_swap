# push_swap

A stack-sorting algorithm challenge: sort a random stack of integers using only two stacks and a fixed set of operations (`push`, `swap`, `rotate`, `reverse rotate`), in as few moves as possible.

The real constraint isn't sorting — it's sorting *efficiently*: a naive approach works, but the project is scored on move count, which forces actual algorithmic thinking about how to minimize operations as the input size grows (from a handful of numbers up to hundreds). A classic algorithmic-thinking exercise, close to what shows up in technical interviews.
